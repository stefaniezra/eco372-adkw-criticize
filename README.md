# ECO372 Week 8: The Case Against ADKW (2010)

Criticizing side replication of Almond, Doyle, Kowalski and Williams (2010, QJE), "Estimating Marginal Returns to Medical Care: Evidence from At-Risk Newborns".

Everything is in [ECO372_ADKW_Criticize](ECO372_ADKW_Criticize). Its [README](ECO372_ADKW_Criticize/README.md) explains how to run the code, where the data come from and what results to expect.

To reproduce: download this repository, set Stata's working directory to the ECO372_ADKW_Criticize folder, and type `do master.do`.
